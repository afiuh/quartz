### 1. 达芬奇密码 · 350分

| 属性 | 内容 |
|------|------|
| 分值 | 350分 |
| 场地 | 随机场地（到达后由教练指引） |
| 提交方式 | 拍摄排序完成后的照片上传 |
| 失败惩罚 | 排序错误冻结 10 秒，重新开始 |

**游戏背景：**
30张图片散落在场地中，每张图片隐含一个 1–30 的数字，队员需要像达芬奇破解密码一样，找出每张图片对应的数字并排序。

**执行步骤：**
1. 到达任务地点后，领取全部 30 张图片
2. 队员分工：部分人负责辨认每张图片代表的数字，部分人负责整理排列
3. 将所有图片按 1→2→3…→30 的顺序依次排列整齐
4. 排列完成后，**全队检查一遍**，确认无误再提交
5. 排序正确后，拍摄一张清晰展示 1–30 完整排序的照片上传

**注意事项：**
- ⚠️ 提交前务必仔细核对，排序错误将冻结 10 秒并重置，浪费时间
- 建议先快速浏览所有图片，找出明显好辨认的数字，再攻克难点
- 拍照时确保 30 张图片都在画面内，排列清晰可辨
- 可以多人同时看不同的图片，加快破解速度

### 2. 七巧板 · 350分

| 属性 | 内容 |
|------|------|
| 分值 | 350分 |
| 场地 | 随机场地（到达后教练提供道具） |
| 道具 | 一套完整七巧板 + 6张图形卡片 |
| 提交方式 | 与带队教练合影上传 |
| 失败处理 | 可重新尝试，无明确冻结惩罚 |

**游戏背景：**
七巧板是中国传统益智玩具，由 7 块几何形状拼成各种图案。队员需要参照卡片图案，依次拼出 6 个指定图形。

**执行步骤：**
1. 到达任务地点，领取七巧板道具（7块：2个大三角、1个中三角、2个小三角、1个正方形、1个平行四边形）和 6 张图形卡片
2. 按照卡片顺序，一张一张来，先完成第 1 张图形，再进行第 2 张
3. 每拼完一个图形后，与卡片核对形状是否一致，确认后继续下一个
4. **依次**完成 6 个图形后即为挑战成功
5. 全队与带队教练合影，拍照上传

**注意事项：**
- ⚠️ 必须"按顺序"完成 6 个图形，不可跳过
- 七巧板的 7 块必须全部用上，不能多也不能少
- 平行四边形有正反两面，拼不上时可以翻转尝试
- 建议 1–2 人专注拼图，其他人对照卡片给出方向提示
- 拼图区域保持整洁，避免零件掉落丢失

### 3. 世界球 · 250分

| 属性 | 内容 |
|------|------|
| 分值 | 250分 |
| 场地 | 随机场地 |
| 道具 | 喷绘世界地图布 + 网球 |
| 提交方式 | 与带队教练合影上传 |
| 失败处理 | 网球落地即重新开始 |

**游戏背景：**
全队共同操控一张巨大的世界地图布，引导网球穿越七大洲四大洋，考验团队默契与配合。

**执行步骤：**
1. 到达场地，由教练展开喷绘地图布并放置网球在起点位置
2. **全体队员**分散站于地图布四周，双手抓住布的白色边缘，将布拉平绷紧
3. 通过队员协调地图布的倾斜方向，控制网球滚动路径
4. 网球需从**起点出发**，途经七大洲（亚洲、欧洲、非洲、北美洲、南美洲、大洋洲、南极洲）和四大洋（太平洋、大西洋、印度洋、北冰洋）
5. 网球到达**终点**后挑战成功
6. 全队与带队教练合影，拍照上传

**注意事项：**
- ⚠️ 全程不得使用道具或身体任何部位（手指、脚等）直接接触网球
- ⚠️ 网球一旦落地即为失败，需重新放回起点开始
- 建议提前分好"方向指挥"角色，统一口令控制布的倾斜
- 转弯处动作要缓慢，防止网球因惯性滚出
- 人数较多时，站位要均匀分布在布的四周

### 4. 会飞的纸币 · 200分

| 属性 | 内容 |
|------|------|
| 分值 | 200分 |
| 场地 | 随机场地 |
| 道具 | 纸币（教练提供） |
| 提交方式 | 拍摄 15 秒视频上传 |
| 成功条件 | 纸币在空中漂浮满 10 秒，全程 15 秒内不落地 |

**游戏背景：**
团队接力吹气，让一枚纸币持续飘浮在空中，考验队员的协调配合与肺活量。

**执行步骤：**
1. 到达场地，由教练提供一张纸币
2. 开始录制 **15 秒视频**（录制前确认摄像稳定，纸币在画面内）
3. 视频开始后，队员抛起纸币，全员轮换对准纸币吹气，使其漂浮
4. 关键目标：**纸币在空中持续漂浮累计达到 10 秒**
5. 15 秒内纸币未落地即挑战成功

**执行建议：**
- 队员站成半圆形或圆形，方便轮换吹气，避免纸币飘出圈外
- 吹气方向应朝**纸币底部**，使其获得向上的浮力
- 指定 1 人负责录制视频，保证画面稳定且能清晰看到纸币全程
- 可先试吹 1–2 次摸清纸币飘动规律，再正式录制
- 风大的环境中选择避风处进行，减少外部干扰

### 5. 颠倒乾坤 · 200分

| 属性 | 内容 |
|------|------|
| 分值 | 200分 |
| 场地 | 随机场地 |
| 道具 | 装有 1/3 水的矿泉水瓶（队员自备或教练提供） |
| 提交方式 | 拍摄 10 秒视频上传 |
| 成功条件 | 10 秒内有 3 人完成瓶子翻转平稳落地 |

**游戏背景：**
流行于网络的"瓶子翻转挑战"（Bottle Flip Challenge）。利用水的重力使瓶子在空中旋转后直立落地，需要技巧与练习。

**执行步骤：**
1. 准备好装有约 1/3 水的矿泉水瓶（水量是关键，过多过少都难成功）
2. 开始录制 **10 秒视频**
3. 视频内，队员依次上场：单手握住瓶身，向上抛出同时使瓶子旋转 **一圈（360°）**
4. 瓶子需离地至少 **30cm** 高度
5. 瓶子旋转一圈后**瓶底平稳落地直立**，即为该队员完成
6. **10 秒内累计 3 人完成**，即挑战成功

**执行建议：**
- 抛瓶技巧：握住瓶子上半部分，手腕向前翻转发力，旋转力度均匀
- 水量建议：瓶子容量的 1/3 是黄金比例，水太少旋转过快，水太多太重
- 建议到达场地前，队员已在路上练习过几次
- 视频录制时，3 人可以依次快速出镜，节省时间
- 选择平坦坚硬的地面，草地、沙地落瓶容易倒

### 6. 跳房子 · 200分

| 属性 | 内容 |
|------|------|
| 分值 | 200分 |
| 场地 | **指定场地**（需前往特定地点） |
| 参与人数 | 全员 5 人参与 |
| 提交方式 | 与带队教练合影上传 |
| 成功条件 | 5 人中有 2 人成功通关 |

**游戏背景：**
跳房子是中国传统儿童游戏，在地面画出格子，单脚或双脚跳跃前进，不能踩线。

**执行步骤：**
1. 前往**指定场地**，由带队教练讲解当日具体规则（格子数量、踩线判定等以现场教练说明为准）
2. 全员 5 人依次参与挑战
3. 按规则单脚/双脚跳过所有格子即为通关
4. **5 人中有 2 人通关**，即为挑战成功
5. 挑战成功后全队与带队教练合影上传

**注意事项：**
- ⚠️ 此项目为**指定场地**，需按地图导航前往，不可在其他地方自行完成
- 踩线或脚落错格子通常判为失败，注意听教练规则说明
- 建议先观察场地格子分布，规划好落脚点
- 挑战顺序可以先让跳跃能力强的队员上，确保先拿到 2 人通关
- 失败队员可根据教练规定决定是否可以重试

### 7. 穿越纸币 · 150分

| 属性 | 内容 |
|------|------|
| 分值 | 150分 |
| 场地 | 随机场地 |
| 道具 | A4 纸 × 1 + 小剪刀 × 1（教练提供） |
| 提交方式 | 与带队教练合影上传 |
| 成功条件 | 把剪成的纸圆圈从全员头到脚套过，圆圈不断开 |

**游戏背景：**
经典的纸张剪切挑战：一张普通 A4 纸，通过折叠剪切可以变成一个能套住所有人的超大圆圈。

**执行步骤：**
1. 到达任务地点，领取 A4 纸和小剪刀
2. **剪纸制作圆圈**（关键步骤）：
   - 将 A4 纸沿长边对折
   - 从折叠边开始，交替向两侧剪出一道道平行切口（不剪断）
   - 展开后，纸张变成一个可以拉伸的大圆圈/纸链
3. 全员**站立围成一团**
4. 将纸圆圈从所有人的**头顶**套入，缓慢向下移动，直到套过**脚踝**
5. 圆圈全程不断开，即为挑战成功
6. 与带队教练合影上传照片

**剪纸技巧：**
- 切口间距越密（约 1–1.5cm 一刀），纸圈拉伸范围越大
- 切口深度约为纸张宽度的 80%，不要剪到头
- 最后沿折叠边剪去两端的连接处（除首尾两刀外），使其连通成圆
- 操作前可先演练一次剪法，避免剪断

**注意事项：**
- ⚠️ 套圆圈时全员动作要慢，避免纸圈撕裂
- 高个子队员先蹲低配合，让圆圈顺利经过最宽处（肩膀/臀部）
- 剪纸时保持安静专注，有一人主导剪纸即可，其他人备用

### 8. 你比划我猜 · 150分

| 属性 | 内容 |
|------|------|
| 分值 | 150分 |
| 场地 | 随机场地 |
| 时间限制 | 倒计时 2 分钟 |
| 提交方式 | 与带队教练合影上传 |
| 成功条件 | 2 分钟内答对 3 题 |
| 失败处理 | 可重新挑战，或放弃该任务 |

**游戏规则：**
队员分成两组，一组用肢体动作表达关键词，另一组猜词，2 分钟内猜对 3 个即成功。

**执行步骤：**
1. 到达任务地点，由教练提供关键词（题目）
2. 队员**分成两组**：
   - **表演组**：看到关键词后，只能用肢体动作表达，**严禁**开口说话、指字、做口型等
   - **猜词组**：根据表演组的动作猜出关键词，可以大声说出答案
3. 教练计时 **2 分钟**开始
4. 每猜对一题，继续下一题，**累计答对 3 题**即为挑战成功
5. 挑战成功后与带队教练合影上传

**表演技巧：**
- 先用动作表现整体概念，再细化关键特征
- 可以用手指比划数字提示字数、音节数
- 遇到抽象词汇，可以用"象征性场景"来表达（如"飞机"就做展翅飞翔动作）
- 表演组内部可以配合，多人同时演不同方面

**注意事项：**
- ⚠️ 表演组绝对禁止：口头提示、指向文字、做口型、写字、比划字形
- 猜词组可以大声猜，猜错不扣分，大胆说
- 2 分钟时间较短，猜不出的词可以果断放弃换下一题
- 建议身体语言夸张一些，让猜词组更容易理解

### 9. 绕口令 · 150分

| 属性 | 内容 |
|------|------|
| 分值 | 150分 |
| 场地 | 随机场地 |
| 时间限制 | 10 秒以内 |
| 提交方式 | 拍摄视频上传 |
| 成功条件 | 10 秒内完整读完绕口令 |
| 失败处理 | 可重新挑战，或跳过该项目 |

**绕口令内容：**

> **红鲤鱼与绿鲤鱼与驴**
>
> 驴小绿家养了红鲤鱼绿鲤鱼和驴。李小丽家养了红驴绿驴和鲤鱼。吕小绿说他家的绿鲤鱼比李小丽家的绿驴绿，李小丽说他家的绿驴比吕小绿家的绿鲤鱼绿。

**执行步骤：**
1. 到达场地，由教练确认绕口令内容
2. 队员自行选定 1 名挑战者（可多人尝试，取最快的一次）
3. 开始录制视频，同时开始计时
4. 挑战者在 **10 秒内**完整、清晰地朗读完上述绕口令
5. 10 秒内读完且无明显错误，即为挑战成功
6. 上传视频

**练习要点：**
- 难点在于"驴/吕/绿/鲤"发音相近，容易混淆
- 建议反复默读记忆，找到自己的节奏感
- 读之前深吸一口气，保证气息充足
- 不必求完美咬字，**速度优先**，10 秒内读完是核心目标

**视频拍摄要求：**
- 拍摄时保证声音清晰可辨
- 画面中能看到说话的人，方便判定是否在读
- 建议竖屏近景拍摄，突出人物表情与口型

### 10. 行走的艺术 · 120分

| 属性 | 内容 |
|------|------|
| 分值 | 120分 |
| 场地 | 随机场地（户外自然环境） |
| 道具 | 自然材料（花朵、树叶、石子等，就地取材） |
| 提交方式 | 拍摄作品照片上传 |
| 成功条件 | 完成一件元素多样、色彩丰富的艺术品 |

**游戏背景：**
你们是一群被职务耽搁的艺术家，现在终于有机会创作！利用大自然中随手可得的材料，拼摆出一件艺术品。

**执行步骤：**
1. 在周边环境中**收集自然材料**：花朵、树叶（不同颜色/形状）、小石子、树枝、泥土等
2. 确定一个平坦的地面或背景作为"画布"
3. 全队共同构思艺术品主题（人物、动物、风景、抽象图案均可）
4. 用收集的材料**拼摆出图案**，注意：
   - 元素要**多样化**（至少用 3 种以上不同材料）
   - 颜色要**丰富**（利用花朵、不同颜色的叶子增加色彩层次）
5. 完成后从正上方或最佳角度**拍摄作品全景照片**
6. 上传照片

**创意建议：**
- 人物轮廓类：用石子勾勒人形，叶子做头发，花朵做装饰
- 动物类：用树枝做骨架，叶子填充身体
- 抽象图案：几何形状、放射状、同心圆等视觉效果好
- 颜色布局参考：绿叶打底，红/黄花朵点缀，白色石子勾边

**拍照建议：**
- 站在高处或站椅子上从正上方俯拍，展示完整作品
- 光线充足时拍摄，避免阴影遮挡作品细节
- 拍照前整理作品边缘，让画面更整洁
