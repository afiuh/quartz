## 四、进行中：Ghidra 全量分析

```powershell
# 1) 查分析是否完成（无 java 进程 = 完成）
Get-Process java

# 2) 等待循环（每 60 秒报一次，直到结束）
while (Get-Process java -ErrorAction SilentlyContinue) { Start-Sleep 60; "还在分析..." }
"分析结束"
Get-Content C:\Users\c3458\GhidraWork\ghidra_analyze.log -Tail 15

# 3) 如果中途挂了，前台重跑（15~45 分钟，跑完自动退出）
& "$GH\support\analyzeHeadless.bat" "$GP" ZoomPlus -import "$R\ZoomPlus.exe" `
  -analysisTimeoutPerFile 5400 -log "C:\Users\c3458\GhidraWork\ghidra_analyze.log"

# 说明：日志里 PNG/GIF/VarnodeContext 等报错均为无害噪音；
#       "ApplyDataArchiveAnalyzer" 是最后一个分析器，之后即完成。
```

## 五、分析完成后：函数定位与反编译（很快）

```powershell
# 1) 函数定位：找出引用目标字符串的代码位置 → 输出 locate 文件
#    注意：Ghidra 12 移除了 Jython，脚本必须是 Java 版（.java）
& "$GH\support\analyzeHeadless.bat" "$GP" ZoomPlus -process ZoomPlus.exe -noanalysis `
  -scriptPath "$R\analysis\ghidra_scripts" `
  -postScript nuitka_locate.java "C:\Users\c3458\GhidraWork\locate_ai_aiming.txt" `
  process_aiming calculate_aim_target calculate_sticky_pull is_head_class "core.ai_aiming" "core\ai_aiming.py"

# 2) 查看定位结果
Get-Content "C:\Users\c3458\GhidraWork\locate_ai_aiming.txt"

# 3) 反编译定位到的函数 → 输出 C 伪代码
& "$GH\support\analyzeHeadless.bat" "$GP" ZoomPlus -process ZoomPlus.exe -noanalysis `
  -scriptPath "$R\analysis\ghidra_scripts" `
  -postScript nuitka_decompile.java "C:\Users\c3458\GhidraWork\locate_ai_aiming.txt" `
  "C:\Users\c3458\GhidraWork\decompiled"

# 4) 查看反编译结果
Get-Content "C:\Users\c3458\GhidraWork\decompiled\decompiled.txt"
```
