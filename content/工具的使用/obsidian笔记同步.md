# Syncthing + Obsidian 跨设备同步使用手册

**适用场景**：Windows 电脑 + Android 手机 同步 Obsidian 笔记库。

---

## 一、设备配对

### 1.1 获取设备 ID

- **电脑端**：管理界面 `http://127.0.0.1:8384` → 右上角"操作"→"显示 ID"
- **手机端**：Syncthing-Fork → 左上角菜单 →"设备 ID"

### 1.2 双向添加

**手机添加电脑**：手机端点击"+"→"添加设备"→粘贴电脑 ID→命名保存

**电脑添加手机**：电脑端"操作"→"添加设备"→粘贴手机 ID→命名保存

---

## 二、文件夹共享

### 2.1 电脑端共享

"添加文件夹"：
- 文件夹 ID：`ObsidianVault`（所有设备保持一致）
- 文件夹路径：选电脑上 Obsidian 笔记库文件夹
- 共享给：勾选手机设备 → 保存

### 2.2 手机端接受

弹窗提示→点击"添加"→设置手机存储路径（如 `/storage/emulated/0/Obsidian/MyVault`）→保存

等待首次同步完成（状态显示"已同步"绿色对勾）。

---

## 三、Obsidian 中打开

手机 Obsidian →"打开其他库"→导航到同步路径（如 `/storage/emulated/0/Obsidian/MyVault`）→选择打开

---

## 四、推荐插件：Syncthing Manager

Obsidian 社区插件搜索安装 **Syncthing Manager**。

配置 API 密钥：
- 电脑 Syncthing：操作→设置→通用→复制 API 密钥
- Obsidian 插件设置中粘贴密钥保存

功能：状态栏显示同步状态、冲突检测、手动触发同步。

---

## 五、进阶配置

### 5.1 排除文件（.stignore）

笔记库根目录创建 `.stignore`：

```
# 排除工作区布局（不同设备屏幕尺寸不同，不同步更好）
/.obsidian/workspace.json

# 排除临时文件
*.tmp
*.log

# 排除大附件（不同步到手机）
/大附件文件夹/
/*.mp4
/*.zip
```

### 5.2 版本控制（防误删）

电脑端：文件夹设置→版本控制→选择"简单版本控制"→保留版本数设为 5

删除的文件会保存在 `.stversions` 文件夹中可恢复。

### 5.3 手机自动同步设置

手机 Syncthing-Fork：设置→运行条件→WiFi 下自动同步，移动数据下暂停

---

## 六、日常使用流程

### 6.1 典型工作流

电脑编辑 → 保存 → 自动同步 → 手机收到更新

手机编辑 → 保存 → 自动同步 → 电脑收到更新

### 6.2 注意事项

| 场景 | 建议 |
|:---|:---|
| 首次启动 | 先开 Syncthing，等同步完成再开 Obsidian |
| 同时编辑同一文件 | 避免，会产生冲突文件 |
| 切换网络 | WiFi→移动数据同步暂停，切回 WiFi 自动恢复 |
| 确认同步状态 | 电脑管理界面或手机 App 显示"已同步" |

## 七、常见问题

**Q1：同步一直"扫描中"**
- 首次同步文件多，耐心等待
- 或在 `.stignore` 排除大文件

**Q2：冲突文件（xxx (conflict).md）**
- Obsidian 打开两个文件，手动合并内容到 `xxx.md`
- 删除冲突文件，保存后自动同步

**Q3：不同网络下无法连接**
- Syncthing 自动尝试中继服务器（速度慢）
- 建议大文件在同一 WiFi 下同步，小量变更走中继

**Q4：手机 Obsidian 看不到新笔记**
- 确认 Syncthing 已同步完成
- Obsidian 中执行"重新加载全部文件索引"
- 或重启 Obsidian

**Q5：电脑管理界面访问不了**
- 检查 Syncthing 是否运行（任务栏图标）
- 地址是否 `http://127.0.0.1:8384`
- 检查端口是否被占用

---

## 八、备份提醒

**同步 ≠ 备份**。建议额外配置：

- **GitHub 私有仓库**：定期 push 笔记（你已在用）
- **外部硬盘**：每周复制一份
- **网盘同步**：定期上传（不要与 Syncthing 同时运行）

不要在同一个 Obsidian 库上同时运行 Syncthing 和 OneDrive 等其他同步工具，极易冲突。

|:---|:---|:---|:---|
| 数据存储 | 设备本地 | 自建服务器 | 官方服务器 |
| 费用 | 免费 | 免费 | 付费 |
| 部署难度 | 低 | 高 | 零 |
| 同步实时性 | 局域网近实时 | 实时 | 实时 |
| 移动端 | Android 优秀，iOS 受限 | 全平台 | 全平台 |
| 数据隐私 | 极高 | 高 | 中等 |
| 冲突处理 | 手动 | 自动 | 自动 |
