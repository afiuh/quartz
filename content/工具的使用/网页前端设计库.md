Awesome DESIGN.md 是一个专门面向 AI 编程时代的开源设计规范集合。你可能遇到过这样的情况：让 AI 生成一个页面，结果出来的界面总是差了点“味道”，不够精致，也缺乏品牌感。**这个项目的核心作用，就是把 Stripe、Apple、Linear 等 60 多个知名品牌的设计语言，翻译成 AI 能够精准理解和执行的 `DESIGN.md` 纯文本文档**。

它的出现，解决了 AI 生成界面时的两个核心痛点：**一是将抽象的审美偏好，转化为 AI 可读的文本约束；二是为 AI 提供了清晰的设计边界，避免了风格不一致和界面平庸的问题**。

### 📖 核心概念：什么是 DESIGN.md？[网页前端设计库](file:///C:%5CUsers%5Cc3458%5CDesktop%5C世界%5C计算机%5CAI%5C网页前端设计库)

`DESIGN.md` 是一个由 Google Stitch 提出的全新概念，它是一个**纯文本的设计系统文档**。它的设计初衷很简单：AI 最擅长理解和处理 Markdown 格式的文本。因此，与其让 AI 去“看图说话”或猜测你的审美，不如直接给它一份写好的、结构化的“设计说明书”。

| 文件 | 谁读取 | 定义什么 |
| :--- | :--- | :--- |
| `AGENTS.md` | 编码代理 | 如何构建项目 |
| **`DESIGN.md`** | **设计代理** | **项目应该长什么样、有什么感觉** |

这份文件不需要复杂的 Figma 导出或 JSON Schema，你只需要把它放在项目根目录下，任何现代的 AI 编码代理（如 Cursor、Claude Code、Google Stitch 等）都能立刻读取并遵循其中的设计规则。

> 📝 **趣味知识**：截至 2026 年 4 月中旬，该项目在 GitHub 上已收获超过 **3.9 万颗星**和近 5000 个分支，是 2026 年第二季度增长最快的开源项目之一。

### 🚀 快速开始：三步为你的项目注入顶级设计

下面，我们将以在 Cursor 中使用 Linear 的设计风格为例，演示如何操作。

1.  **获取 DESIGN.md 文件**
    *   你可以通过两种方式获得：
        *   **方法 A (CLI 工具，推荐)**: 在你的项目终端中，直接运行以下命令，工具会自动将最新的 `DESIGN.md` 文件添加到你的项目根目录。
            ```bash
              npx getdesign@latest add linear.app > ./DESIGN.md
            ```
            关于此命令的详细解释，请参考下方的“如何获取更多规范？”章节。
        *   **方法 B (手动下载)**: 访问 [getdesign.md](https://getdesign.md/) 网站，浏览并找到你心仪的品牌（例如 Linear），点击进入后复制其 `DESIGN.md` 文件的内容，并在你的项目根目录下创建同名文件。

2.  **放置文件**
    *   确保 `DESIGN.md` 文件位于你项目的**根目录**。

3.  **与 AI 协作**
    *   打开你的 AI 编程助手（如 Cursor 的 Composer 或 Chat），输入如下提示词：
        ```
        请根据项目根目录的 DESIGN.md 文件，为我创建一个数据仪表盘页面。
        ```

就是这么简单！现在，AI 生成的代码将严格遵循 Linear 的设计风格，从配色、字体到间距，都将保持高度一致。

> 💡 **技巧**：你也可以直接在 AI 编程助手的对话中，要求它帮你完成第一步。例如，对 Cursor 说：“请帮我用 `npx getdesign@latest add linear.app` 命令，将 Linear 的设计规范添加到我的项目中。”

### 📁 文件结构解析：一个 DESIGN.md 里有什么？

一个完整的 `DESIGN.md` 文件并非随意的描述，而是由 9 个结构化的模块组成，为 AI 提供了从宏观到微观的全面设计指引。

| 模块 | 它告诉 AI 什么 |
| :--- | :--- |
| 1. 视觉主题与氛围 | 页面的整体感觉：是极简、还是充满活力？密度是高还是低？ |
| 2. 颜色与角色 | 精确的色值（HEX）以及每种颜色的用途（如：品牌色、成功色、警示色）。 |
| 3. 字体排印 | 字体家族、字重、行高，以及完整的标题/正文层级表。 |
| 4. 组件样式 | 按钮、卡片、输入框等核心组件的默认、悬停、激活等状态样式。 |
| 5. 布局原则 | 间距刻度（如 4px 基础单位）、网格系统、留白哲学。 |
| 6. 深度与层级 | 阴影系统，定义不同元素（如弹窗、卡片）的表面层级。 |
| 7. 设计准则 | 明确告诉 AI “该做什么”和“不该做什么”，提供设计护栏和反模式。 |
| 8. 响应式行为 | 断点设置、触控目标大小、不同屏幕下的折叠/适配策略。 |
| 9. 提示词指南 | 提供给 AI 的快速颜色参考和即用提示词，方便快速调用。 |

### 💡 进阶玩法：如何获取更多规范？

`awesome-design-md` 项目本身是一个精选合集，你可以在其 [GitHub 仓库](https://github.com/afiuh/awesome-design-md) 中找到所有现有的规范。但如果你想获取更多的设计规范，或生成自己的设计文档，可以使用 `getdesign` 这个配套工具。它有几种不同的用法：

*   **添加已有规范**: 通过 `add <品牌域名>` 的方式，将社区已有的 `DESIGN.md` 规范添加到你的项目中。
    ```bash
    npx getdesign@latest add linear.app
    ```
*   **提取网站规范**: 这是它的核心功能之一。你可以让工具分析任何公开网站的 CSS 样式，并自动生成一份 `DESIGN.md` 文件。
    ```bash
    npx getdesign@latest extract https://你的目标网站.com
    ```
    这条命令会尝试抓取目标网站的视觉风格，并将其整理成结构化的设计文档，为你节省大量手动分析的时间。

*   **请求新规范**: 如果你需要的品牌规范尚未收录，可以在 [getdesign.md/request](https://getdesign.md/request) 提交请求。这是一个付费优先服务，可以为你生成特定网站（包括私有网站）的设计规范。
