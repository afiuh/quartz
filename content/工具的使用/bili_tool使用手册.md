# bili_tool 使用手册

> 写给自己的操作指南。系统替你跑管道，你只需要阅读、批注、交流。

---

## 一、这是什么

一个自动帮你从 B站 挖掘高质量深度内容的系统。它每天凌晨运行（或你手动触发），从你的关注链和收藏夹出发，全网挖掘候选视频，经过三层筛选，用 AI 精校字幕后写入你的 Obsidian。

**你只需要做三件事**：阅读推荐笔记 → 写批注 → 跟 AI 助手聊聊看法。

---

## 二、每日使用节奏

```
早晨打开 Obsidian
  → 查看笔记/AI推荐的视频/ 下的最新推荐
  → 逐条阅读
  → 在感兴趣的视频下方写批注（💬 逐段看法 / 📝 总体评论）
  → 读完一条勾选 ✅ 已阅
  → 全部读完 → 告诉 AI 助手"看完了"
  → AI 读取你的批注，跟你讨论
  → 讨论完勾选 ✅ 已交流
  → 下一个凌晨自动生成新一轮推荐
```

**重要规则**：只有上一批推荐**全部已阅**后，系统才会生成下一批。所以看完记得勾已阅。

---

## 三、推荐笔记的结构

每篇推荐笔记（如 `推荐-2026-06-10.md`）包含多条视频，每条视频格式如下：

### 基本信息表

| 字段 | 说明 |
|------|------|
| 标题 | 视频原标题 |
| UP主 | UP主名称 + UID |
| 时长 | 视频总时长 |
| BV号 | B站视频编号（可点击跳转） |
| 分类 | 话题分类（历史权谋/哲学思辨/影视解读...） |

### 内容分析

AI 对视频的初步判断：
- **核心论点**：这个视频到底在说什么
- **论证结构**：论点的组织方式
- **信息密度**：干货比例

### 精校文本与批注

这是最核心的部分。AI 已经把视频字幕逐段整理好，并标注了 💡 亮点和 ⚠️ 不足。你可以在任意段落后面写下自己的看法。

### 建议表

| 建议 | 理由 |
|------|------|
| 关注/不关注/黑名单 | 系统对这个 UP 主的初步判断 |

### 复选框

```
- [ ] 已阅      ← 你看完这条就勾上
- [ ] 已交流    ← AI 跟你讨论完再勾
```

## 四、如何写批注（核心操作）

这是你与系统交互的唯一方式。在 Obsidian 中直接编辑推荐笔记，用以下三种标记：

### 方式一：💬 逐段看法

穿插在精校文本的段落之间，对 AI 精校的**具体某一段**发表看法。

```markdown
## 第三段：朱元璋的用人逻辑

...（AI 精校的文本）...

💡 亮点：此处用"藩王-官僚"二元框架解释洪武朝的政治清洗，视角新颖

💬 这个框架有意思，但我觉得他忽略了朱元璋个人性格因素。
单纯用制度解释有点机械，洪武的很多决策明显带着草根出身的报复心理。
```

**写法**：直接在 💡/⚠️ 后面换行，用 `💬` 开头写你的看法。

### 方式二：📝 视频评论

在笔记末尾，对该视频的**整体评价**。

```markdown
## 📝 视频评论

这个UP主的史料功底不错，但分析框架太松散，东一榔头西一棒子。
不如渤海小吏那种一根主线穿到底的讲法。不关注。
```

### 方式三：💬 总体反馈

在笔记末尾，对**推荐系统本身**的建议。

```markdown
## 💬 总体反馈

最近推的历史类太多了，好久没看到哲学类的好内容了。
能不能多往毛选、辩证法方向搜一搜？
```

## 五、批注后的反馈闭环

你的批注不是写了就完了——系统会自动解析并分级处理。

### 三级反馈表

| 你说的 | 系统怎么做 | 要不要确认 |
|--------|-----------|-----------|
| "完全不喜欢"、"别再推了"、"拉黑" | 直接拉黑 UP 主 | ❌ 不需要 |
| "多推"、"喜欢"、"关注了" | boost 该方向权重 | ❌ 不需要 |
| "不够严谨"、"还行吧"、"有点意思但…" | 记入待确认列表 | ✅ 下次对话问你 |
| "我更看重UP主有没有一手资料" | 讨论后提炼为新画像维度 | ✅ 深度讨论 |

### 权重如何变化

- 每条已交流的反馈 → 话题权重 ±0.03
- 拉黑 → 对应风格标签直接清零
- 新维度 → 初始权重 0.5，连续 3 次正向反馈后锁定

### 实际例子

```
你说：这个UP主完全不行，论证全是情绪输出，别再推了
  → auto 级 → UP主拉黑 + 情绪化分析标签降权

你说：不够严谨
  → ask 级 → 记入 .pending_questions.json
  → 下次对话 AI 问你："你指的严谨是论证逻辑、数据引用、还是结论可靠性？"
  → 你回答后 AI 更新对应维度
```

## 六、如何启动

### 手动运行

打开终端（CMD 或 PowerShell），进入项目目录：

```bash
cd C:\Users\c3458\Desktop\世界\草稿\agent

# 完整管道（推荐）
python run_daily.py

# 或者分步
python -m bili_tool.cli discover    # 只发现候选
python -m bili_tool.cli score       # 只打分
python -m bili_tool.cli analyze     # 只精校

# 查看状态
python -m bili_tool.cli status
```

### 定时自动运行

通过 Hermes cron 设置凌晨 3 点自动执行（后续配置）：

```bash
hermes cron create "0 3 * * *" --prompt "运行 python run_daily.py 生成今日B站推荐"
```

## 八、常见问题

### Q：运行后没生成新笔记？

1. 检查是否有未阅笔记：`python -m bili_tool.cli status`
2. 全部已阅才会生成下一批

### Q：B站 API 报错？

SESSDATA 过期了。步骤：
1. 浏览器打开 B站，F12 → Application → Cookies
2. 找到 `SESSDATA`，复制值
3. 更新 `bili_tool\.env` 中的 `BILI_SESSDATA=`

### Q：GPU 转录失败？

```bash
# 检查 GPU
nvidia-smi
# 测试转录
python -m bili_tool.cli test-asr
```

### Q：精校文本有省略？

这是红线，不应该发生。告诉 AI 助手"你有省略"，它会重新生成完整版本。

### Q：怎么让 AI 助手帮我分析笔记？

在 Hermes 中说：
- "看看最新推荐"
- "处理反馈"
- "加载B站skill"

AI 会自动读取你的批注并跟你讨论。

## 九、你当前的偏好画像

> 以下是你与 AI 多轮交流后提炼的核心偏好，驱动推荐引擎。持续更新中。

### 喜欢的内容

| 方向 | 关键词 | 偏好风格 |
|------|--------|----------|
| 历史权谋分析 | 权谋/博弈/制度/权力结构 | 渤海小吏式分析框架，反常识，因果链清晰 |
| 哲学思辨 | 毛选/马克思主义/辩证法 | 有明确方法论，能解释现实问题 |
| 影视深度解读 | 新三国/大明王朝1566 | 系统拆解，人物行为逻辑分析 |

### 明确不喜欢

纪录片、有声书、电视剧原片、儿童内容、催眠助眠、高考应试、人生感悟/心灵鸡汤、纯娱乐搞笑。

### 评判标准（按优先级）

1. 论证严谨性 > 趣味性
2. 框架原创性 > 叙事流畅度
3. 信息密度 > 视频时长
4. 批判力度 > 迎合情绪

### 量化阈值

| 维度 | 值 |
|------|-----|
| 视频时长 | 5min ~ 180min，偏好 30min+ |
| 论证密度 | 每千字 ≥ 0.5 个可验证断言 |
| 开篇要求 | 模糊开篇 → 立即降权 |

## 十、与 AI 助手的协同

### 在 Hermes 中触发

说这些关键词 AI 会自动加载 bili_tool skill：

| 你说的 | AI 做什么 |
|--------|----------|
| "看看推荐"/"最新笔记" | 读取 Obsidian 中的最新推荐 |
| "处理反馈"/"分析批注" | 解析你的 💬/📝/💬，分级处理 |
| "run_daily"/"跑一下管道" | 执行完整每日管道 |
| "拉黑 BVxxx 的UP主" | 加入黑名单 |
| "最近推的怎么样" | 查看统计和历史 |
| "加载B站skill" | 兜底命令，确保 skill 已加载 |

### 交流流程

1. 你在 Obsidian 写完批注 → 来 Hermes 说"处理反馈"
2. AI 读取你的批注 → 逐条分析 → 提问确认模糊点
3. 你回答 → AI 确认理解 → 勾选 ✅ 已交流
4. 画像自动更新 → 下次推荐更精准

### 画像持续进化

你每次跟 AI 深入讨论一个视频，AI 都会尝试从中提炼新的偏好维度。比如之前讨论渤海小吏的视频时，提炼出了：
- `criticism_tolerance`: 只接受基于事实的批判
- `claim_density_min`: 每千字 0.5 个可验证断言
- `vague_intro_penalty`: 开篇模糊直接降权

随着使用，你的偏好画像会越来越精细。
