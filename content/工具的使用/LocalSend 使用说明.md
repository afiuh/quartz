# LocalSend 使用说明

## 一、软件简介

LocalSend 是一款免费、开源、跨平台的本地文件传输工具，可在同一局域网内的设备之间快速传输文件、文件夹和文本。与依赖外部服务器的传输工具不同，LocalSend 使用 REST API 和 HTTPS 加密实现设备之间的点对点安全通信，无需互联网连接。支持 Windows、macOS、Linux、Android 和 iOS 全平台。

**核心特性：**

- **隐私安全**：所有文件通过局域网直传，不经过任何第三方服务器，杜绝云端泄露风险
- **无限制传输**：不限制文件大小和数量
- **无需注册登录**：安装后即可使用，无需任何账号
- **去中心化**：不依赖中央服务器，纯本地网络传输
- **开源免费**：源代码公开透明，无广告、无数据收集

## 二、界面布局

LocalSend 主界面设计简洁，共有三个核心页面：

### 接收页面（Receive）
显示当前设备的名称和状态，用于接收其他设备发送的文件。

### 发送页面（Send）
用于选择待发送的文件、文件夹或文本内容，并显示附近可用的接收设备。

### 设置页面（Settings）
可在此修改设备名称、文件保存路径、主题、语言等个性化配置。


## 三、使用前的准备

在使用 LocalSend 传输文件之前，请确保：

1. **所有设备连接至同一局域网**：传输方和接收方必须连接到同一个 Wi-Fi 网络或同一路由器下的有线网络。
2. **所有设备均已启动 LocalSend**：保持应用在前台运行状态。
3. **网络权限已授予**：
   - iOS 设备首次使用时会弹出提示，需允许 LocalSend 访问本地网络
   - 如遇防火墙阻拦，需确保允许 LocalSend 在本地网络中通信（默认端口为 53317）

> **注意**：某些路由器（如企业网络或公共 Wi-Fi）可能启用了“AP 隔离”或“客户端隔离”功能，这会阻止设备之间互相发现。若遇此情况，可尝试使用手机热点创建临时局域网。


## 四、发送文件

### 方式一：自动发现发送

1. 在发送端点击 **“发送”** 按钮，进入发送界面。
2. 选择要发送的内容：
   - **选择文件**：点击“选择文件”按钮，在弹出的窗口中选取文件或文件夹（支持多选）
   - **拖拽添加**：直接将文件或文件夹拖拽到发送区域
   - **发送文本**：点击“文本”选项，粘贴要发送的文本内容
3. 等待数秒，下方 **“附近设备”** 区域会自动列出同一局域网内的其他设备。
4. 点击目标接收设备的名称，发送请求。

接收端会弹出接收提示，点击 **“接受”** 后即开始传输。传输完成后，接收端文件默认保存在设备的 Downloads/LocalSend 目录下。

### 方式二：手动输入 IP 或 hashtag 连接

当自动扫描失败（如企业网络限制了设备发现协议）时，可绕过广播机制，通过 IP 地址或 hashtag 直接建立连接。

1. 在接收端“接收”界面，点击右上角的“信息”图标，查看本机的 IP 地址和端口（如 `192.168.1.137:53317`）以及 hashtag（如 `#137`）。
2. 在发送端“发送”界面，找到 **“手动输入”** 或 **“+ 添加设备”** 选项。
3. 输入接收端的完整 IP 地址与端口，或仅输入 hashtag（如 `#137`），点击确认。
4. 在列表中点击手动添加的设备，即可发起传输。

### 方式三：链接分享

此方式允许未安装 LocalSend 的设备（如临时借用的电脑）通过浏览器接收文件。

1. 在发送端进入设置，启用 **“通过链接分享”** 选项。
2. 可选择设置 PIN 码保护、开启自动接收或设定过期时间。
3. 生成后获得一个 HTTP 链接及对应的二维码，接收端使用浏览器打开链接即可下载文件。


## 五、接收文件

### 自动接收（需要确认）
这是默认模式。当其他设备发送文件时，接收端会弹出请求提示，点击 **“接受”** 即可开始接收，点击 **“拒绝”** 则取消本次传输。

### 快速保存（无需确认）
如果在同一可信网络中频繁互传文件，可开启“快速保存”功能，文件到达后自动保存至预设路径，无需每次手动确认。

**设置方法：**
1. 进入 **设置** 页面。
2. 找到 **“快速保存”** 或 **“自动接收”** 开关并开启。
3. 文件将自动保存到设置中指定的目录。

### PIN 码保护（增强安全）
为防止未经授权的访问，可在设置中启用 PIN 码验证。开启后，每次接收文件时需输入预设的 PIN 码，增强安全性。


## 六、批量操作与多设备传输

### 批量选择文件
- 按住 `Ctrl`（Windows/Linux）或 `Cmd`（macOS）可多选多个文件
- 支持直接选择整个文件夹，系统会递归添加文件夹内的所有文件
- 支持从其他应用直接分享多个文件到 LocalSend

### 多接收者模式
如需向多个设备同时发送相同的文件，可使用多接收者模式：
1. 在发送页面右上角点击设置图标
2. 选择 **“多个接收者”** 模式
3. 选择文件后，每个目标设备旁都会显示独立的发送按钮，可分别点击进行连续发送

### 传输状态监控
在多接收者模式下，每个设备的传输状态独立显示，便于实时了解各设备的传输进度。


## 七、快捷键与快捷操作

**桌面端（Windows/macOS/Linux）：**
- `Ctrl/Cmd + O`：快速选择文件
- `Ctrl/Cmd + Shift + F`：查找设备
- `Ctrl/Cmd + ,`：打开设置

**移动端手势：**
- 下拉刷新：重新扫描设备
- 长按文件：进入批量操作模式
- 双指缩放：调整文件列表视图


## 八、个性化设置

### 修改设备名称
进入设置页面，找到 **“别名”** 选项，输入自定义的设备名称，保存后需重启应用生效。

### 修改文件保存路径
在设置中找到 **“保存位置”** 选项，可自定义默认接收文件的存储目录。

### 安全设置
- **启用/禁用加密**：安全环境可关闭 HTTPS 加密以提升传输速度
- **PIN 码保护**：防止他人随意发送文件造成打扰
- **自动接收开关**：控制是否需要手动确认每次接收

### 界面主题
支持跟随系统、浅色模式、深色模式等多种主题切换。

### 端口配置
默认监听端口为 53317，如需自定义可在设置的高级选项中修改（需勾选“高级配置”）。

### 便携模式
可将 LocalSend 应用程序和配置文件一起存储在 U 盘或移动硬盘中，实现配置随行、即插即用。在可执行文件同目录下创建一个名为 `settings.json` 的空文件，启动应用后会自动初始化配置。


## 九、常见问题与排错

### 1. 设备无法互相发现

**可能原因及解决方法：**
- **未连接同一网络**：检查所有设备是否连接至同一个 Wi-Fi 或同一条网线下的局域网
- **AP 隔离/客户端隔离**：某些路由器启用了此功能会阻止设备互访，可尝试关闭该功能或换用手机热点
- **防火墙阻拦**：检查防火墙设置，确保允许 LocalSend 使用本地网络通信（端口 53317）
- **应用未活跃**：确保双方 LocalSend 应用都已打开，且设备未进入休眠状态
- **iOS 网络权限**：确保 iOS 设备已授予 LocalSend 本地网络访问权限

若上述方法无效，可尝试使用手动输入 IP 地址的方式连接。

### 2. 传输速度较慢

传输速度主要受局域网环境限制。在同一良好 Wi-Fi 下，各平台组合的典型速度如下：
- Windows → Windows：80-120 MB/s
- macOS → iOS：50-80 MB/s
- Android → Windows：30-60 MB/s
- Linux → macOS：70-100 MB/s

可尝试以下优化：靠近路由器以增强信号、减少网络中的其他大流量任务、关闭 HTTPS 加密（安全环境下）。

### 3. 文件传输失败

- 确保接收端有足够的存储空间
- 传输大文件时保持设备不进入休眠状态
- 检查网络连接是否稳定，避免传输过程中断开

### 4. 配置迁移后连接异常

若将便携模式配置从一台设备迁移到另一台设备后出现连接问题，可能是证书不匹配所致。建议在目标设备上删除 `settings.json` 文件，让 LocalSend 自动重新生成新的安全证书。


## 十、隐私与安全说明

LocalSend 采用 **TLS/HTTPS 加密**，所有数据在传输过程中均被加密保护。由于是点对点本地传输，文件不会上传至任何云端服务器，也没有任何广告或数据收集行为。作为开源软件，其代码公开在 GitHub 上，任何人都可以审查和验证其安全性。
