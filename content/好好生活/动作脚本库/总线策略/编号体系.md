# 编号体系

## 格式

**分类前缀-动作首字母**

- 分类前缀：两位数字
- 动作首字母：核心动词拼音首字母，大写

## 分类前缀对照

| 前缀 | 分类 |
|------|------|
| 01 | 个人卫生 |
| 02 | 事前准备 |
| 03 | 物品清洁 |
| 04 | 物品整理 |

## 首字母提取规则

1. 取脚本标题中核心动词的拼音首字母
2. 默认取两字首字母，如“洗脸”→ XL，“洗澡”→ XZ
3. 若两字首字母与其他脚本冲突，扩展到三字，如“洗拖鞋”→ XTX
4. 保持最短不冗余

## 文件命名

**编号_脚本名.md**

示例：
- 01-XZ_洗澡.md
- 01-XL_洗脸.md
- 03-XW_洗碗.md
- 04-GW_归位杂物.md

## 注意事项

- 总线策略文件本身不编号，编号仅用于四个动作分类下的脚本
- 脚本删除后，其首字母组合可重新分配给新脚本
