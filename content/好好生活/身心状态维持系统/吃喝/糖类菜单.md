### 糖类菜单

#### 米制品
**第1级：基础米制品（一个人，极简操作）**

1. **白粥**：大米 + 水。淘米、加水、下锅煮。
    
2. **白米饭**：大米 + 水。淘米、加水、电饭锅煮。
    
3. **二米粥**：大米 + 小米。混合淘洗、加水、下锅煮。
    
4. **红糖大米粥**：大米 + 红糖 + 水。淘米、加水、加红糖、下锅煮。
    

**第2级：加料升级版（一个人，营养升级）**

1. **蛋炒饭**：米饭 + 鸡蛋 + 葱花。炒蛋盛出，炒饭，合炒，调味。
    
2. **西红柿鸡蛋盖饭**：米饭 + 鸡蛋 + 西红柿。炒西红柿鸡蛋，盖在热米饭上。
    
3. **玉米鸡蛋粥**：大米 + 玉米粒 + 鸡蛋。粥加玉米同煮，好时打蛋花。
    

**第3级：有条件时的复杂米制品（家人代工或费时操作）**

1. **煲仔饭**：米饭 + 腊肠/腊肉 + 青菜。需要砂锅和火候控制，家人代工。
    
2. **海鲜粥**：大米 + 虾/蟹/鱼片 + 姜丝。需要新鲜海鲜和处理技巧，家人代工。
    
3. **八宝粥**：大米 + 多种豆类 + 干果 + 糖。食材多，需提前浸泡，费时。
    

**第4级：外食精品米制品（完全外包）**

1. **煲仔饭**：专业煲仔饭店，有锅巴有料汁。
    
2. **粥品专门店**：皮蛋瘦肉粥、及第粥、艇仔粥等。
    
3. **盖浇饭类**：宫保鸡丁盖饭、鱼香肉丝盖饭、咖喱鸡饭等。
    
4. **炒饭类**：扬州炒饭、菠萝炒饭等专业炒饭。
    
5. **寿司/饭团**：日式外食选项，便当类。
#### 面制品
**第1级：基础食物**

1. **酱油汤面**：挂面 + 生抽 + 盐。煮面，调汤，捞面。
    
2. **素拌面**：挂面 + 现成拌面酱。煮面，拌酱。
    
3. **清汤面（配蛋）**：挂面 + 鸡蛋 + 盐。煮面，打蛋花，调味。
    
4. **馒头**
**第2级：来点操作**

5. **西红柿鸡蛋面**：挂面 + 鸡蛋 + 西红柿。炒西红柿出汁，加水煮面，打蛋。
    
6. **绿叶菜鸡蛋面**：挂面 + 鸡蛋 + 绿叶菜。煮面，加菜，打蛋。
    
7. **葱花鸡蛋面**：挂面 + 鸡蛋 + 小葱。煮面，打蛋，出锅撒葱花。
    
8. **瓜类鸡蛋面**：挂面 + 鸡蛋 + 黄瓜/冬瓜/西葫芦。瓜切片，与面同煮，打蛋。
    

**第3级：外面买点吧**

1. **兰州牛肉面**：可选毛细、二细、韭叶、大宽等。
    
2. **油泼面**：扯面 + 蒜末 + 辣椒面 + 热油。可选加油泼炸酱、油泼西红柿鸡蛋。
    
3. **馄饨**：小馄饨（纯肉）、大馄饨（菜肉）、广式云吞。
    
4. **刀削面**：可选猪肉臊子、牛肉、西红柿鸡蛋。
    
5. **炒面**：鸡蛋炒面、肉丝炒面、炒拉条、炒刀削。
    
6. **拌面类**：土豆烧牛肉拌面，担担面、炸酱面、热干面。
