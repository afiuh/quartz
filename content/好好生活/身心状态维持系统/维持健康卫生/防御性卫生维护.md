### 个人清洁 · 执行策略

本模块基于已有的动作脚本库，通过对脚本的调用频率、触发条件和耦合方式进行精确设计，实现个人清洁的零决策成本和高执行效率。

**一、每日核心流程**

此流程与晨起、睡前两个时间点刚性绑定，作为每日必须完成的基础维护。

| 时间点    | 执行脚本                                               | 说明                            |
| ------ | -------------------------------------------------- | ----------------------------- |
| **晨起** | `01-SY 刷牙`、`01-XL 洗脸`、`01-TX 剃须`（隔日）`01-XT 洗头`（每日） | 基础清洁，唤醒身体。                    |
| **睡前** | `01-SY 刷牙`、`01-XL 洗脸`、`02-XJ 洗脚`（每日）               | 彻底清洁，准备入睡。洗头与洗澡解耦，确保每日头部的清爽感。 |
==注意，由于洗澡可以直接包含洗头洗脸洗脚，所以我们要么在早晨直接洗澡，要么在晚上直接洗澡，这样效率最快==

**二、隔日常规流程**

此流程与隔日一次的洗澡事件绑定。

- **执行脚本**：`01-XZ 洗澡`、`01-MX 抹香`、`01-TX 剃须`
    
- **执行逻辑**：洗澡时，顺序执行 `01-XZ 洗澡`（含洗头、洗脸），并耦合执行 `01-MX 抹香` 与 `01-TX 剃须`（如果当日与隔日频率吻合）。
    
- **补充触发**：剧烈运动并出汗后，立即调用 `01-XZ 洗澡` 脚本，不受隔日频率限制。
    

**三、高频独立触发任务**

此部分任务由特定生活事件驱动，频率不定，但必须即时响应。

| 脚本         | 触发条件                                                                                                                           |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `02-XS 洗手` | **餐食相关**：饭前、处理食物残渣后。  <br>**个人护理相关**：如厕后；接触泪液、鼻涕等体液后；处理伤口前后。  <br>**外部接触后**：外出回家；接触公共设施、快递、垃圾或钱币后。  <br>**感官触发**：手部有明显脏污或黏腻感时。 |
| `01-MY 抹药` | 睡前抹                                                                                                                            |

**四、低频维护任务**

此部分任务有固定的时间窗口，或由生理信号触发。

| 脚本           | 推荐频率  | 执行策略                                                            |
| ------------ | ----- | --------------------------------------------------------------- |
| `01-JZ 剪指甲`  | 每3天一次 | **时间窗口**：每周末固定时段检查并修剪。  <br>**即时触发**：指甲过长影响操作（打字、握笔），或出现倒刺、劈裂时。 |
| `01-RC 抹润唇膏` | 按需    | 当唇部感觉干燥或紧绷时立即执行，或环境特别干燥时预防性使用。                                  |

**五、补充说明**

- **`02-XJ 洗脚`**：此脚本目前为占位编号，具体动作流程待补充入库。执行逻辑为：每日睡前执行，但若当日已通过 `01-XZ 洗澡` 完成足部清洁，则可跳过。
    
- **执行原则**：所有脚本均为纯动作指令，执行时意识自由，只看一遍步骤，身体自动完成。完毕即退出，不记录、不复盘、不标记完成。


### 环境清洁 · 执行策略

本模块与“个人清洁”并列，同属“防御性卫生维护”。核心目的是通过一系列清洁整理行为，维持一个洁净、有序、低风险的私人物理空间，为深度思考提供无干扰的环境基础。所有脚本当前仅定义核心目的，具体动作步骤留待后续完善。

**一、卧室区域**

此区域是你休息与长时间工作的核心空间，维护质量直接影响睡眠恢复与思考专注度。

|脚本编号|脚本名称|核心目的|
|---|---|---|
|`02-CP`|床铺维护|定期更换清洗床单、被罩、枕套等贴身物品，维持睡眠微环境的洁净卫生，防止因尘螨或污渍影响睡眠质量与皮肤健康。|
|`02-ZM`|桌面维护|整理桌面物品，使其归位至固定位置，清除与当前工作无关的视觉干扰，保持工作区整洁有序，减少因杂乱引发的微焦虑与注意分散。|
|`02-KQ`|空气维护|通过定时开窗通风或使用空气净化设备，保持室内空气流通与清新，避免因空气污浊导致的大脑缺氧、注意力下降与不适感。|
|`02-DM`|地面维护|清扫或擦拭地面，清除灰尘、毛发与细小杂物，维持整体视觉洁净感，防止灰尘堆积引发呼吸道不适或过敏。|
|`02-WC`|蚊虫防治|主动检查并清除室内蚊虫，或提前设置物理（蚊帐）与化学（电蚊香）屏障，确保睡眠期间不受物理滋扰，保护极其脆弱的入睡条件。|

**二、衣物护理**

此区域负责个人衣物的清洗、干燥、收纳与特殊维护，是维持外在得体与内在秩序感的关键环节。

|脚本编号|脚本名称|核心目的|
|---|---|---|
|`03-XY`|洗衣|定期收集待洗衣物，通过清洗去除污渍、汗味与细菌，维持衣物基本洁净，防止因衣物不洁导致的皮肤问题或社交不适。|
|`03-LS`|晾晒|将洗净衣物及时、充分地晾晒或烘干，确保彻底干燥，防止因潮湿环境滋生细菌与霉菌，产生异味。|
|`03-SN`|收纳|将干燥衣物折叠或悬挂，归位至衣柜内固定位置，保持衣柜整洁有序，消灭“找衣服”带来的微决策与视觉混乱。|
|`03-TS`|特殊护理|处理需特殊维护的物品（如鞋子、背包等），通过擦拭、保养等手段维持其功能与外观，延长使用寿命，减少重复购买的决策与成本。|

**三、设计逻辑与说明**

- **边界限定**：本模块严格限定在个人完全可控的私人区域（宿舍卧室）。生活功能区（如卫生间、厨房）等公共区域不在本策略维护范围内，由其所属的公共卫生系统负责。
    
- **低维护成本**：所有脚本均遵循“纯动作指令”原则，执行时意识自由。脚本之间独立，按需触发，无提醒、无打卡、无统计。
    
- **后续完善**：当前仅为框架定义。后续需为每个脚本编写具体的、原子化的动作步骤，并存入动作脚本库，形成完整的执行闭环。
