### 第一阶段：活动立项——统筹者可行性调查清单

**触发条件**：有人向你提出活动想法（无论谁是发起人），你作为统筹，接收以下信息：

- 活动内容（具体干什么事）
    
- 预计时长
    
- 需要的校内空间场所
    
- 招收孩子的数量和年级
    
- 需要什么物料
    

**收到这些信息后，你作为统筹，需要亲手摸清以下三件事：**

---

#### 一、场地可行性调查

| 要搞清楚的问题                | 怎么做                                      |
| ---------------------- | ---------------------------------------- |
| 场地当天那个时段是否空闲？          | 公共场地就是提前占位或者预约，非公共场地去调查这个场地归谁管，然后去联系相关的人 |
| 有没有可能临时被占用？（考试、会议、维修等） | 这个场地平常是谁用？一般什么情况下会用，这些慢慢调查去              |
| 如果场地突然不能用，有没有备选？       | 看看有没有可能的替补场地，有最好，没有的话就确保这个场地百分百可用        |
|                        |                                          |


**你需要拿到的结果**：场地在活动期间明确可用，对于场地被临时占用的情况都有预案

---

#### 二、成员可用性调查

统筹在这一步要做的是：**本次活动需要什么岗位**

| 岗位    | 本场活动是否需要 |
| ----- | -------- |
| 主讲老师  |          |
| 助教    |          |
| 安全员   |          |
| 后勤    |          |
| 拍摄    |          |
| 情绪观察员 |          |

**你需要拿到的结果**：确定本次活动需要什么岗位，为后面找人做好准备


---

#### 三、活动内容可执行性推敲

**以统筹的视角，推演一遍能不能跑通。**

- **时间逻辑**：给出的环节，塞进给定的时长里，是刚好还是明显撑不下？比如“30分钟讲完5个展厅”，你就要在现场提醒主讲控制节奏
    
- **空间逻辑**：环节之间的动线设计合不合理？有没有来回跑冤枉路的情况？能不能优化成一个闭环？
    
- **人员逻辑**：每个环节，哪个角色在主带、哪个在配合、哪个在盯安全？有没有某个角色在某个时段被“双线作战”同一时间干两件事儿，这种情况要避免
    

---

#### 四、判定结论

以上三件事摸完，作为统筹给出结论：

- ✅ **可以启动**：场地、人员、内容逻辑都没问题 → 进入下一阶段（前期准备）
    
    
- ❌ **建议暂缓**：关键场地拿不到、最低人数凑不齐 → 如实反馈给我，说明缺什么


### 第二阶段：前期准备——从定人到定案

#### 步骤一：岗位征岗

**你要做的事**：

- 根据立项阶段确定的岗位需求，做一个共享表格（在线文档）。
    
- 表格里列出所有岗位（主讲、助教、安全员、殿后者、后勤、拍摄、情绪观察员等），每个岗位写清楚职责简述和当天到场时间。
    
- 把表格发到团队群里，让成员在截止时间前自行填表认领岗位。
    
- 如果有岗位多人争抢或无人认领，你私下协调，最终每个岗位都有人落位。
    

**你需要拿到的结果**：所有岗位确认完毕，每个人都知道自己当天是什么角色。

---

#### 步骤二：推演流程初稿

**你要做的事**：

1. **先问主讲**：你需要什么配合？每个环节你希望助教怎么协助？有没有特殊的空间需求或设备需求？
    
2. **开始推演**：把活动从开始到结束的每一个环节，用时间线的方式拉出来。推演的时候拿着立项阶段的“活动内容可执行性推敲”那三条对照：
    
    - 时间逻辑：塞不塞得下？
        
    - 空间逻辑：动线顺不顺？
        
    - 人员逻辑：每个环节谁主带、谁配合、谁盯安全？有没有人同一时间被两头拉？
        
3. **产出初稿**：一份按时间轴展开的流程表，每个时段写明做什么、谁负责、谁配合。
    

**你需要拿到的结果**：一份统筹方案初稿（就是你现在手上那种详细到分钟的执行表）。

---

#### 步骤三：物料定案与采购

这个步骤要跟推演同步做，因为每个环节需要什么物料，是在推演的时候才能确定的。

**你要做的事**：

- 在推演流程时，逐一问：这个环节需要什么物料？需要多少份？
    
- 把物料需求结合常用物料库整理成清单，格式类似：
    

| 物料名称 | 规格/要求 | 预计数量 | 用于哪个环节 | 备注     |
| ---- | ----- | ---- | ------ | ------ |
| 奖励贴纸 | 卡通款   | 20张  | 分组比拼奖励 | 多备2张防丢 |
| ...  | ...   | ...  | ...    | ...    |
|      |       |      |        |        |

- 把这份清单交给负责财务的人，让他去调查：哪儿买最划算？给链接、给价格、给预计总花费。
    
- 财务反馈后，你把购买任务交给后勤，后勤按链接和数量执行购买，超出预计花费的钱，买的时候就及时跟财务反馈，说明白哪儿多花了，物料购买完毕后要告知统筹
    
    
**你需要拿到的结果**：物料全部到位，数量清点无误。

---

#### 步骤四：实地演练，定最终方案

**时间点**：活动前2天。

**你要做的事**：

- 约上主讲和助教（最少这两个角色，其他人能来更好），按流程初稿完整走一遍。
    
- 不是坐那儿开会，是真的一个环节一个环节走，主讲模拟讲解，助教模拟配合，你站在统筹视角观察。
    
- 演练时重点看：
    
    - 各个环节的时间卡不卡得上，现场可能会有什么意外，主讲有没有对应的控场方案
        
    - 在现场结合现实场景，结合小孩的动线，具体设计团队成员的站位
        
    - 活动过程中，物料该什么时候怎么摆，该什么时候收，放到哪里
          
          
        
- 演练结束后，立刻根据发现的问题调整流程初稿，形成**最终版统筹方案**。
     
**你需要拿到的结果**：一份经过实地验证的、可执行的最终方案，所有参与角色都清楚自己在每个环节要干什么。

### 第三阶段：现场指挥——统筹者的职责与动作指南


#### 一、活动开始前（碰头会 + 准备期）

**你的角色**：定心丸 + 最后一道检查。

| 你要做的事            | 具体怎么做 |
| ---------------- | ----- |
| **确认全员就位**       |       |
| **确认物料到手**       |       |
| **确认每个人都懂自己的任务** |       |
| **确认天气和场地最终状态**  |       |


---

#### 二、活动进行中（你的主战场）

**你的角色**：节拍器 + 防火墙。

**1. 流程守护——确保活动不偏离轨道**

| 你要盯什么      | 发现偏差怎么掰回来                                                |
| ---------- | -------------------------------------------------------- |
| **时间进度**   | 拿表对着看。某个环节超时了，提前用手势或纸条提醒主讲：“还剩5分钟，需跳过__。” 主讲没反应，直接上前轻声告知 |
| **站位是否正确** | 扫一眼各角色是否站在表里规定的位置。错了就手势示意纠正                              |
| **衔接是否流畅** | 哪个角色该上了，你看他没反应过来，提醒一下                                    |


**2. 复杂问题兜底**

出现计划之外的问题，统筹去处理，其他角色不要管，而且处理的时候要隔离，不要影响到大局

**3. 临时补位——链条不能断**
例子

| 缺位情况                 | 你怎么补                          |
| -------------------- | ----------------------------- |
| **安全员带娃上厕所**         | 你就暂时当一会儿安全员                   |
| **助教临时走开，主讲需要人配合**   | 你顶上去做配合，配合完马上退出来恢复观察全局        |
| **后勤要分物料，拍摄需要补一个镜头** | 你帮后勤递物料，让拍摄去抓拍。但你绝不长时间陷在具体事务里 |

**补位原则**：补位是暂时的，顶上去时要快速判断谁能更快回来，一旦那人回来或找到替代者，你立刻脱身回到观察位。

---

#### 三、活动收尾时

| 你要盯的事     | 具体动作                          |
| --------- | ----------------------------- |
| **孩子交接**  | 安排签退                          |
| **物料回收**  | 盯后勤是否清点回收所有物料、马甲、器材，确认场地无遗留   |
| **所有人撤离** | 所有孩子被接走、场地恢复、团队成员集合后，你宣布活动结束。 |
### 第四阶段：活动复盘——即时经验收集

**时机**：活动结束后，所有人还没散、场地还没收拾完的时候，就地围一圈，花5-10分钟。

**主持**：统筹。

**规则**：每人想想这三个问题，有想法就说，没想法就不说

- 这次有什么**做法/安排**特别好，下次可以照搬？
    
- 哪个**游戏**孩子反应好、大人带起来也顺？
    
- 哪句**话术**说出去效果特别好？
    

**统筹自己的任务**：记录信息，和你的想法合并，去掉重复的，直接归档整理到研学知识库里
