# 计算机领域的基础能力（"润滑剂"型技能）

> 核心观点：编程领域有两类基础能力——一是英语水平，二是键盘操控与打字水平。它们是"无处不在的润滑剂"，没有也能干活，但会麻烦、会慢。这类能力都是**复利型**技能，不会随技术迭代贬值，越早投入回报越高；而框架、语言等"知识型"技能会过时。

## 一、输入/操作层（手）

| 能力         | 说明                | 瓶颈等级 |
| ---------- | ----------------- | ---- |
| 打字水平       | 盲打 + 速度，重点是"不看键盘" | 软    |
| 快捷键/工具肌肉记忆 | vim、IDE 快捷键、终端操作  | 软    |
|            |                   |      |

## 二、信息获取层（眼）

| 能力 | 说明 | 瓶颈等级 |
|---|---|---|
| 英语 | 读报错、文档、搜索，**阅读 > 写作**；AI 时代写作可外包，阅读理解不可外包 | 硬 |
| 搜索能力 | 选关键词、用搜索语法、知道搜什么（卡住的本质是"不知道搜什么"） | 硬 |
| 命令行/文件系统 | 终端、路径、环境变量心智 | 中 |

## 三、思维处理层（脑）

| 能力 | 说明 | 瓶颈等级 |
|---|---|---|
| 抽象与命名 | 变量/函数起名、模块拆分，写代码一半时间在"想清楚叫什么、放哪" | 硬 |
| 拆解问题 | 大问题切成可验证的小步骤，决定"要不要卡住" | 硬 |
| 调试思维 | 定位根因、二分排查，与拆解互补 | 硬 |

## 四、表达协作层（嘴/笔）

| 能力 | 说明 | 瓶颈等级 |
|---|---|---|
| 提问能力 | 把"这不对"变成"输入/预期/实际"三要素，沟通成本直接减半 | 中 |
| 文档与注释 | 用母语把逻辑讲清楚，和英语互补 | 软 |

## 五、可持续层（身）

| 能力 | 说明 | 瓶颈等级 |
|---|---|---|
| 专注力 | 编程是长耗时的注意力马拉松 | 软 |
| 久坐/健康管理 | 身体健康是持续性的润滑剂 | 软 |

## 核心排序（个人观点）

> **搜索 > 抽象命名 > 拆解问题 > 英语 > 命令行 > 提问 > 其余**

## 特点总结

- 都是**复利型**技能：越早投入回报越高，不会随技术迭代贬值
- 英语是硬门槛：报错信息、文档、Stack Overflow、API 命名全依赖它
- 打字更像软实力：真正的瓶颈不是速度，而是"不看键盘"和快捷键肌肉记忆
