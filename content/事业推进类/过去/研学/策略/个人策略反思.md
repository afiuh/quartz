# 最源头的判断失误与研学行业拆解

## 一、政策误判：从文字到落地的落差

- **核心问题**：对政策的判断失误——政策文字描述的“利”与实际落地后的执行方式**千差万别**。
- **实际案例**：阿尔西办公立学校时遭遇“不守信、人情世故重”。
- **教训**：
  - 只看到政策的“利”，没有调研这些利会如何**具体流动**。
  - 要让层层经手的利益流到自己手里，难度远超想象。
- **认知注意点**：不要相信纸上的“应该”，要调研现实中的“实际”。

## 二、研学行业的本质与结构

### 2.1 行业本质

> 说白了就是带小孩做活动，然后从家长手里拿钱。其他的都是修饰。

- **门槛**：不高。
- **竞争点**：不断“修饰加料”——本省→跨省→跨国，看谁玩得大。

### 2.2 行业三层结构

| 圈层       | 角色           | 关键特征            |
| -------- | ------------ | --------------- |
| **教练圈层** | 执行层（带活动）     | 门槛低，容易被替代       |
| **对接圈层** | 资源整合（找人、找场地） | **核心圈层**，极度依赖人脉 |
| **合作圈层** | 外部合作方（提供空间等） | 包络万象            |

- **关键**：进入对接圈层需要积累大量人脉。
- **现实**：深耕十多年的“老家伙们”不会轻易分享人脉。
- **红海困局**：新人即使再努力，大多只能被困在教练圈层，顶多沦为某个对接圈层的**附庸**。

## 三、值不值得？

> 花掉自己最宝贵的年华就为了当个附庸，值吗？

- **答案**：不值。
- **即便混到对接圈层**：我也不喜欢——周而复始地对接、谈合作、办活动、收钱——“真无聊”。
- **核心矛盾**：这不是钱的问题，而是这种重复性、无创造空间的劳动不符合我的道心。

## 四、当前策略（第一次收钱活动）

1. **先干完**第一次收钱的活动。
2. **观察回报**：我的心理价位是 **500元**。
3. **分情况决策**：
   - **给得多（>500）**：留久一点，但**慢慢抽身**。
   - **给得少（<500）**：快速抽身。
1. **试探对方**：看看他们短时间内是否还能找到新的总统筹者。
   - 大概率不能。
   - 这一抽身试探有效，可以倒逼对方加价或接受离开。

## 五、总结与提醒

- 策略：干完，拿钱，根据金额决定抽身速度。
- **核心不是钱**，而是不要被困在这个行业里当附庸。
# 关于付广这一方向的分析

## 一、付广的定位与模式

- 付广属于**对接层**，搞各种活动和项目。
- 与阿尔西的不同：付广在大学里有职位，可以**低成本利用大学生**作为人力资源。
- 运作方式：找机会、谈合作、拉大学生团队、做项目 → 做成了收一茬钱 → 周而复始。
- **本质**：和阿尔西没有区别，都是对接圈层的重复性劳动。

## 二、核心问题：付广这个人不行

- **缺乏边界感**，方式与手段太“歪”。
- 结论：**竖子不足与谋**。

## 三、更根本的制约：大学里的人脉壁垒

- 大学里的人脉壁垒比外部更严重。
- 新人很难突破既有圈层，只会被困在更底层。

## 四、共同的隐忧：他们已看穿我不可驯服

- 付广和阿尔西应该都看出来了：**我不是他们能驯服的人**。
- 他们明里暗里给我下定义、设限制。
- 如果我跟着他们中的任何一个，都会被**恶意制约**。

## 五、总结

- 两条路（阿尔西 / 付广）本质相同，都是无效选择。
- 付广个人品质更差，不值得合作。
- 他们对我已采取防御姿态，加入只会被压制。
